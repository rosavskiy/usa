## ❌ Если есть проблемы:

**Проверьте:**
1. Node.js установлен? → `node --version` в PowerShell
2. .env файл заполнен правильно?
3. Supabase база создана?
4. OpenAI баланс положительный?
5. Оба терминала запущены?

**Типичные ошибки:**
- "npm not found" → переустановите Node.js
- "Database connection failed" → проверьте DATABASE_URL
- "OpenAI error" → проверьте API key и баланс
- "Port in use" → измените PORT в .env
