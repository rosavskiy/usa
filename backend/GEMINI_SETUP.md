# Google Gemini AI Setup

Google Gemini предоставляет бесплатный API для парсинга текста с высокой точностью.

## Преимущества Gemini для парсинга

✅ **Бесплатно:** 1500 запросов в день (достаточно для большинства случаев)
✅ **Точность:** ~92-95% (намного лучше regex)
✅ **Понимает контекст:** Различает "Baseline Allowance" от реального потребления
✅ **Без кредитной карты:** Не требует платёжной информации для начала
✅ **Быстрый:** 1-2 секунды на парсинг
✅ **Vision API:** Может парсить напрямую с изображения (без OCR)

## Получение API ключа

### Шаг 1: Перейти на AI Studio

Открой: https://ai.google.dev/

### Шаг 2: Войти в Google аккаунт

Нажми **"Get API key in Google AI Studio"**

### Шаг 3: Создать API ключ

1. Нажми **"Get API key"** в верхнем меню
2. Выбери **"Create API key in new project"**
3. Скопируй сгенерированный ключ (начинается с `AIza...`)

### Шаг 4: Добавить в .env

Открой `C:\usa\backend\.env` и добавь:

```env
GEMINI_API_KEY=AIzaXXXXXXXXXXXXXXXXXXXXXXXXXXXX
```

### Шаг 5: Перезапустить backend

```bash
cd C:\usa\backend
npm run dev
```

## Как это работает

### Текущий процесс (с Gemini):

```
1. Загрузка изображения счета
   ↓
2. EasyOCR извлекает текст (бесплатно)
   ↓
3. Gemini AI парсит текст в JSON (бесплатно, 1500/день)
   ↓
4. Если Gemini недоступен → Regex парсинг (fallback)
   ↓
5. Результат: точные данные о счёте
```

### Альтернатива - Gemini Vision (будущая опция):

```
1. Загрузка изображения
   ↓
2. Gemini Vision: изображение → JSON (минуя OCR)
   ↓
3. Результат
```

## Лимиты бесплатного tier

| Модель | Запросов в минуту | Запросов в день |
|--------|-------------------|-----------------|
| Gemini 1.5 Flash | 15 | 1500 |
| Gemini 1.5 Pro | 2 | 50 |

**Для нашего приложения:** Используем Gemini 1.5 Flash (быстрый, точный, 1500/день).

**Что если превысить лимит?**
Система автоматически переключится на regex парсинг.

## Примеры парсинга

### SoCalGas счёт:
```
Вход (OCR текст):
"ACCOUNT NUMBER 011 022 7183 5
Total Amount Due $40.56
37 Therms
Baseline Allowance: 54 Therms"

Выход (Gemini JSON):
{
  "type": "gas",
  "provider": "SoCalGas",
  "amount": 40.56,
  "consumption": {
    "value": 37,  // ✅ Не спутал с Baseline (54)

  ...
}
```

## Проверка работы

1. Перезапусти backend
2. Загрузи любой счет
3. В логах должно быть:

```

📄 Gemini raw response: {"type":"gas",...
✅ Gemini parsed successfully
📊 Type: gas
💰 Amount: 40.56
⚡ Consumption: 37 therms
```

## Troubleshooting

### API ключ не работает

**Ошибка:** `API key not valid`
**Решение:** Проверь, что ключ скопирован полностью (начинается с `AIza`)

### Превышен лимит

**Ошибка:** `RESOURCE_EXHAUSTED`
**Решение:** Подожди 24 часа или система автоматически переключится на regex

### Gemini возвращает плохие данные

**Причина:** Очень плохое качество OCR текста
**Решение:** 
1. Улучши качество фото счёта
2. Попробуй другой OCR сервис (Azure CV)
3. Система автоматически попробует regex fallback
